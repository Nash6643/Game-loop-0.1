# Java 2D Game Engine

A modular 2D Game Engine built with Java Swing and AWT.

## Key Features
- **AABB Physics & Collisions:** Bounding box collision system with trigger zones and static obstacles.
- **Particle System:** Real-time particle emitter with velocity, gravity, and lifetime decay.
- **Camera & State Framework:** Smooth lerping 2D viewport camera with serializable scene state snapshotting.
- **Tilemap Engine:** Grid-based tilemap rendering layer with CSV serialization support.
- **HUD & Debug Overlay:** Interactive debug panel for controlling entity scales, movement speed, and wireframe bounds.
